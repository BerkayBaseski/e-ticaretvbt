# Architecture & Design System Documentation

- **`architecture/`**: High-level component relationship diagrams, state management patterns, and FSD layer boundaries.
- **`api/`**: API specifications, REST payload examples, RFC 9457 error contracts, and rate limiting limits.
- **`database/`**: Relational database schema reference, foreign key rules, and indexing guidelines.
- **`design-system/`**: Color palettes, dark/light theme tokens, typography hierarchy, and accessibility standards.
- **`development/`**: Onboarding guide for new developers, branch naming conventions, and code review checklists.
- **`deployment/`**: Future deployment strategies, domain DNS setup, and environment variable configuration (no infrastructure manifests created).
- **`decisions/`**: Architecture Decision Records (ADRs) tracking technical trade-offs and framework choices.
- **`assets/`**: High-resolution branding logos, screenshots, and exported architecture diagrams.
