# Product & Engineering Documentation Center

Welcome to the centralized documentation workspace for the E-Commerce platform:

```text
docs/
├── architecture/         # System design, FSD architecture & component diagrams
├── api/                  # REST API SLAs, endpoints & payload specs
├── database/             # Schema specs (3NF), ERD diagrams & index strategy
├── design-system/        # Color tokens, typography & UI component guidelines
├── development/          # Local setup, coding standards & git workflow
├── deployment/           # Deployment guidelines (Reserved for future ops documentation)
├── decisions/            # Architecture Decision Records (ADR)
└── assets/               # Branding assets, UI mockups & architecture diagrams
```
