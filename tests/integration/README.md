# Integration & Accessibility & Performance Test Blueprints

- **`integration/`**: Component interactions, Form validation checks (React Hook Form + Zod), Store state transitions (Zustand).
- **`accessibility/`**: Automated WCAG 2.1 Level AA color contrast, screen reader ARIA labels, and keyboard navigation testing.
- **`performance/`**: Core Web Vitals benchmarking (LCP, CLS, FID) and k6 API load testing.
- **`visual-regression/`**: Cross-browser visual diff snapshot testing for design system components.
- **`fixtures/`**: Static test JSON payloads and user state factories.
- **`mocks/`**: Test environment mock handlers and network stubs.
